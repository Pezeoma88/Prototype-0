# TipTap

TipTap is a simple mobile tip calculator created for Prototype 0. The app allows users to enter a bill amount, select a tip percentage, and calculate the tip and total bill.

## Features

- Enter a bill amount
- Select a 15%, 18%, or 20% tip
- Calculate the tip amount
- Calculate the total bill
- Reset the calculator
- Handles empty or invalid bill amounts
